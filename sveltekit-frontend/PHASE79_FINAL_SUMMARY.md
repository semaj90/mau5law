```
[1] READ FILE → Extract structure (imports, types, functions, keywords)
[2] ERROR CONTEXT → Query database for file-specific errors
[3] RAG/KAG QUERY → Build rich query with file summary + errors
[4] LLM PROMPT → Generate with full context (file analysis + KB solutions)
[5] VALIDATE → 4-layer check: code vs doc, syntax, quotes, duplicates
[6] RANK → Composite score: (validation × 0.6) + (similarity × 0.4)
[7] OUTPUT → JSONL with file path, scores, confidence level
```
