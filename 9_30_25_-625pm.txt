  the variant prop. You can see the available variants and the CSS classes they apply in the <script> section
  of each file.

  T8 KV-cache during engine build

  When you later build a TensorRT engine, keep KV-cache in INT8.

  INT8 cache + INT4 weights = lower VRAM, longer sequences fit, fast token generation.

  ✅ Ampere GPUs (RTX 3060 Ti) support INT8 natively; INT4 is emulated but still efficient for weight-only.

  3️⃣ FlashInfer / fused attention (optional)

  If you build TensorRT-LLM later, enable FlashInfer kernels (--enable_context_fmha) for fused attention → 1.5×–2× throughput increase.

  On Ampere, this helps reduce memory bandwidth bottlenecks.

Here’s a ready-to-use script:

wsl bash -c "cat > ~/full_trtllm_pipeline.sh << 'EOF'
#!/usr/bin/env bash
# Full TRT-LLM pipeline: quantize → convert → build → test
# Optimized for Gemma3, RTX 3060 Ti (8GB VRAM)

set -e
TRT_ENV=~/trt_env_310
MODEL_HF=~/gemma3_checkpoint_working
MODEL_TRTL=~/gemma3_trtllm_checkpoint
ENGINE_DIR=~/gemma3_trtllm_int4

# Step 0: Activate environment
echo '🔹 Activating TRT-LLM environment...'
source \$TRT_ENV/bin/activate

# Step 1: Wait for PyTorch INT4 quantization to finish
echo '🔹 Waiting for PyTorch INT4 quantization to complete...'
while pgrep -f 'quantize_gemma3_pytorch_int4.py' >/dev/null; do
    echo '⏳ Quantization still running...'
    sleep 30
done
echo '✅ Quantization finished.'

# Step 2: Convert HF/Unsloth checkpoint → TRT-LLM checkpoint
echo '🔹 Converting checkpoint to TRT-LLM format...'
python3 -m tensorrt_llm.models.gemma.convert \
  --model_dir \$MODEL_HF \
  --output_dir \$MODEL_TRTL \
  --dtype float16 \
  --tp_size 1 --pp_size 1

# Step 3: Build INT4 AWQ + INT8 KV cache engine
echo '🔹 Building INT4 AWQ + INT8 KV cache engine with FlashInfer...'
python3 -m tensorrt_llm.commands.build \
  --checkpoint_dir=\$MODEL_TRTL \
  --output_dir=\$ENGINE_DIR \
  --max_batch_size=2 \
  --max_input_len=1024 \
  --max_seq_len=2048 \
  --use_weight_only \
  --weight_only_precision=int4_awq \
  --int8_kv_cache \
  --enable_context_fmha \
  --paged_kv_cache \
  --remove_input_padding \
  --use_gemm_plugin=auto \
  --use_gpt_attention_plugin=float16

# Step 4: Quick inference test
echo '🔹 Running quick inference test...'
python3 -m tensorrt_llm.commands.run \
  --engine_dir=\$ENGINE_DIR \
  --input_text 'Summarize Article 1 of the U.S. Constitution in one sentence.'

echo '✅ TRT-LLM full pipeline completed successfully!'
EOF
chmod +x ~/full_trtllm_pipeline.sh && echo '✅ Full pipeline script created'
"

✅ Usage

After creating it:

wsl bash -c "~/full_trtllm_pipeline.sh"


It automatically waits for your PyTorch quantization.

Converts to TRT-LLM checkpoint.

Builds the engine with INT4 AWQ + INT8 KV cache + FlashInfer.

Runs a test inference at the end.
