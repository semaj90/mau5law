## 🎯 Key Features

### High Performance
- **2000 errors/batch** (20x faster than 100/batch)
- **Streaming JSONL** (no full file load)
- **Checkpoint/resume** (survive crashes)

### Intelligent Routing
- **≥85% confidence** → Auto-apply
- **70-85%** → Human validation
- **50-70%** → Use external tools
- **<50%** → Escalate to human

### Hybrid Knowledge
- **RAG (60%)** → Qdrant semantic search
- **KAG (40%)** → Neo4j graph traversal
- **Fusion ranking** → Best of both worlds

### Continuous Learning
- **Every 5 minutes** → Policy updates
- **Track success rates** → Per tool/error type
- **Adapt prompts** → Based on learned patterns
