# Using recommendations.jsonl: Complete Guide

This guide explains how to use the JSONL dataset generated by Phase 79 Direct Patch Generation.

## What is recommendations.jsonl?

A JSONL (JSON Lines) file where each line is a ranked error recommendation with:
- Error code
- Validation score (0-100)
- Cosine similarity to knowledge base (0-1)
- Ranking metrics (1-10 scales)
- Confidence level (HIGH/MEDIUM/LOW)

## File Format Example

```jsonl
{"error_code":"TS1005","rank":1,"cosine_similarity":0.92,...}
{"error_code":"TS2304","rank":2,"cosine_similarity":0.87,...}
{"error_code":"TS1109","rank":3,"cosine_similarity":0.81,...}
```

## Reading the File

### PowerShell Examples

**Read all recommendations:**
```powershell
Get-Content recommendations.jsonl | ConvertFrom-Json
```

**Get top 10 by rank:**
```powershell
Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Select-Object -First 10 `
  | Format-Table rank, error_code, composite_score, confidence_level
```

**Filter by confidence level:**
```powershell
Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Where-Object { $_.confidence_level -eq 'HIGH' } `
  | Sort-Object composite_score -Descending `
  | Select-Object rank, error_code, composite_score
```

**Count by confidence:**
```powershell
Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Group-Object confidence_level `
  | Select-Object Name, Count
```

**Export to CSV for analysis:**
```powershell
Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Export-Csv -Path recommendations.csv -NoTypeInformation
```

### Node.js Examples

**Read all recommendations:**
```javascript
import fs from 'fs';

const lines = fs.readFileSync('recommendations.jsonl', 'utf-8').split('\n').filter(l => l);
const recommendations = lines.map(l => JSON.parse(l));

console.log(`Total: ${recommendations.length} recommendations`);
```

**Get top 10:**
```javascript
const top10 = recommendations.slice(0, 10);
console.table(top10.map(r => ({
  rank: r.rank,
  error: r.error_code,
  score: r.composite_score,
  confidence: r.confidence_level
})));
```

**Filter by confidence:**
```javascript
const highConfidence = recommendations.filter(r => r.confidence_level === 'HIGH');
console.log(`High confidence patches: ${highConfidence.length}`);
```

## Understanding the Rankings

### Composite Score (Main Metric)
**Formula:** `validation_score * 0.6 + similarity_score * 100 * 0.4`

- **60% weight:** How valid the patch is (0-100)
- **40% weight:** How similar to known solutions (0-100)

**Interpretation:**
- 80-100: Excellent - apply first
- 60-79: Good - apply second
- 40-59: Fair - apply last
- <40: Questionable - review manually

### Similarity Rank (1-10)
**Based on:** Cosine similarity to knowledge base solutions

```
Cosine Similarity → Rank (1-10) → Inverse Rank (1-10)
0.91-1.0 ────────→ 10 ────────→ 1 (BEST)
0.81-0.9 ────────→ 9 ─────────→ 2
0.71-0.8 ────────→ 8 ─────────→ 3
0.61-0.7 ────────→ 7 ─────────→ 4
0.51-0.6 ────────→ 6 ─────────→ 5 (MIDDLE)
0.41-0.5 ────────→ 5 ─────────→ 6
0.31-0.4 ────────→ 4 ─────────→ 7
0.21-0.3 ────────→ 3 ─────────→ 8
0.11-0.2 ────────→ 2 ─────────→ 9
0.0-0.1  ────────→ 1 ─────────→ 10 (WORST)
```

**Use inverse_rank_1_to_10 for apply order:**
- Rank 1: Apply first (best match)
- Rank 5: Apply middle
- Rank 10: Apply last (worst match)

### Validation Score
**Range:** 0-100%

**Score breakdown:**
- >80%: Patch is definitely valid code
- 50-80%: Patch is likely valid, minor issues
- <50%: Patch may have syntax problems

**Factors that affect validation:**
- Code vs documentation ratio
- Balanced braces/brackets/parentheses
- Valid string quotes
- No duplicate patterns
- TypeScript/JavaScript syntax correctness

## Apply Strategy

### Conservative (Safest)
Apply only HIGH confidence + composite score >85:
```powershell
$safe = Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Where-Object { $_.confidence_level -eq 'HIGH' -AND $_.composite_score -gt 85 } `
  | Sort-Object inverse_rank_1_to_10

$safe | ForEach-Object {
  Apply-Patch -ErrorCode $_.error_code -Patch $_
}
```

### Balanced (Recommended)
Apply HIGH + MEDIUM confidence with composite >70:
```powershell
$balanced = Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Where-Object { $_.composite_score -gt 70 } `
  | Sort-Object composite_score -Descending

$balanced | ForEach-Object {
  Apply-Patch -ErrorCode $_.error_code -Patch $_
}
```

### Aggressive (All Valid Patches)
Apply all patches with validation_score >50:
```powershell
$all = Get-Content recommendations.jsonl `
  | ConvertFrom-Json `
  | Where-Object { $_.validation_score -gt 50 } `
  | Sort-Object composite_score -Descending

$all | ForEach-Object {
  Apply-Patch -ErrorCode $_.error_code -Patch $_
}
```

## Analysis Commands

### Summary Statistics
```powershell
$data = Get-Content recommendations.jsonl | ConvertFrom-Json

$stats = @{
  'Total Recommendations' = $data.Count
  'High Confidence' = ($data | Where-Object { $_.confidence_level -eq 'HIGH' }).Count
  'Medium Confidence' = ($data | Where-Object { $_.confidence_level -eq 'MEDIUM' }).Count
  'Low Confidence' = ($data | Where-Object { $_.confidence_level -eq 'LOW' }).Count
  'Avg Composite Score' = [math]::Round(($data.composite_score | Measure-Object -Average).Average, 2)
  'Avg Validation Score' = [math]::Round(($data.validation_score | Measure-Object -Average).Average, 2)
  'Avg KB References' = [math]::Round(($data.kb_references | Measure-Object -Average).Average, 2)
}

$stats | Format-Table -AutoSize
```

### Distribution by Composite Score
```powershell
$data = Get-Content recommendations.jsonl | ConvertFrom-Json

@('80-100', '60-79', '40-59', '<40') | ForEach-Object {
  $range = $_
  $count = switch -regex ($range) {
    '80-100' { ($data | Where-Object { $_.composite_score -ge 80 }).Count }
    '60-79'  { ($data | Where-Object { $_.composite_score -ge 60 -AND $_.composite_score -lt 80 }).Count }
    '40-59'  { ($data | Where-Object { $_.composite_score -ge 40 -AND $_.composite_score -lt 60 }).Count }
    '<40'    { ($data | Where-Object { $_.composite_score -lt 40 }).Count }
  }
  Write-Host "Score $range`: $count patches"
}
```

### KB Reference Analysis
```powershell
$data = Get-Content recommendations.jsonl | ConvertFrom-Json

@(0, 1, 2, 3) | ForEach-Object {
  $refs = $_
  $count = ($data | Where-Object { $_.kb_references -eq $refs }).Count
  Write-Host "With $refs KB references: $count patches"
}
```

## Troubleshooting

### File is Empty
```powershell
# Check if file exists
Test-Path recommendations.jsonl

# Check file size
(Get-Item recommendations.jsonl).Length

# Check if database had errors to process
psql -c "SELECT COUNT(*) FROM compile_errors WHERE error_code IS NOT NULL;"
```

### File has Wrong Format
```powershell
# Verify JSONL format (each line must be valid JSON)
$content = Get-Content recommendations.jsonl
$content | ForEach-Object {
  try { $_ | ConvertFrom-Json | Out-Null; Write-Host "✓ Line OK" }
  catch { Write-Host "✗ Invalid JSON: $_" }
}
```

### Scores Seem Wrong
```powershell
# Check calculation
$rec = Get-Content recommendations.jsonl -First 1 | ConvertFrom-Json

Write-Host "Composite score: $($rec.composite_score)"
Write-Host "Calculated: $([math]::Round($calc, 1))"
```

## Performance Optimization

### Filter Before Loading All
For large files (1000+ recommendations):
```powershell
# Instead of loading all then filtering:
Get-Content recommendations.jsonl | Select-String 'HIGH' | ConvertFrom-Json

# Or use a loop for memory efficiency:
$count = 0
Get-Content recommendations.jsonl | ForEach-Object {
  $rec = $_ | ConvertFrom-Json
  if ($rec.composite_score -gt 85) {
    $count++
    $rec
  }
}
```

### Process in Batches
```powershell
$data = @(Get-Content recommendations.jsonl | ConvertFrom-Json)
$batchSize = 50

for ($i = 0; $i -lt $data.Count; $i += $batchSize) {
  $batch = $data[$i..($i + $batchSize - 1)]
  Write-Host "Processing batch $([math]::Ceiling($i / $batchSize))..."

  # Apply batch
  Apply-PatchBatch -Patches $batch
}
```
