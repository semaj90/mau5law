Load all errors + vectors from Postgres\n2. Greedy clustering with cosine similarity\n3. Group errors with same code + high similarity (>0.92)\n4. Compute centroid for each cluster\n5. Store in `phase72_cluster` table\n\n**Configuration:**\n- `PHASE73_SIM_THRESHOLD=0.92` – Adjust for tighter/looser clustering\n- Lower = more clusters, higher = fewer clusters\n\n### Phase 73: Summarization\n\n**Process:**\n1. Find clusters without summaries\n2. Sample 6 representative errors per cluster\n3. Call `gemma3-legal:latest` to generate summary\n4. Embed summary with `embeddinggemma:latest`\n5. Store in Postgres + Qdrant\n\n**Configuration:**\n- `PHASE73_MAX_CLUSTERS=100` – Max clusters to process\n- `PHASE73_SAMPLES_PER_CLUSTER=6` – Sample size for summaries\n\n### Phase 78: Fix Suggestions\n\n**RAG Process:**\n1. Embed new error with `embeddinggemma:latest`\n2. Search Qdrant `phase72_summaries` for similar clusters\n3. Use top 5 matches as context\n4. Call `gemma3-legal:latest` with context\n5. Return specific, actionable fix\n\n---\n\n## 🔍 Querying the Brain\n\n### Find clusters by size\n\n```sql\nSELECT label, size, cycle\nFROM phase72_cluster\nWHERE phase = 72 AND cycle = 1\nORDER BY size
