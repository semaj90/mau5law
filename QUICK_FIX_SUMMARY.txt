PROBLEM
═══════════════════════════════════════════════════════════════════════════════

Error when running: npm run dev  or  npm run dev:quic

  [ioredis] Unhandled error event: ReplyError: NOAUTH Authentication required

CAUSE: Empty password + wrong Redis port configuration


SOLUTION (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Open sveltekit-frontend/package.json

Step 2: Find and replace these TWO lines:

  LINE 7:  "dev": "cross-env DEV_BYPASS_AUTH=true REDIS_URL=redis://localhost:6380 REDIS_PASSWORD= node scripts/start-dev-dynamic.js",
  TO:      "dev": "cross-env DEV_BYPASS_AUTH=true REDIS_URL=redis://:redis@localhost:6379 REDIS_PASSWORD=redis node scripts/start-dev-dynamic.js",

  LINE 19: "dev:quic": "cross-env DEV_BYPASS_AUTH=true REDIS_URL=redis://localhost:6380 REDIS_PASSWORD= node scripts/start-full-stack.js",
  TO:      "dev:quic": "cross-env DEV_BYPASS_AUTH=true REDIS_URL=redis://:redis@localhost:6379 REDIS_PASSWORD=redis node scripts/start-full-stack.js",

Step 3: Save file and run:

  npm run dev
  or
  npm run dev:quic


WHAT CHANGED
═══════════════════════════════════════════════════════════════════════════════

  BEFORE:                           AFTER:
  ──────────────────────────────    ──────────────────────────────
  redis://localhost:6380            redis://:redis@localhost:6379
  REDIS_PASSWORD=                   REDIS_PASSWORD=redis
  (empty password)                  (password embedded in URL)
  (test Redis instance)             (main Redis instance)


WHY IT WORKS
═══════════════════════════════════════════════════════════════════════════════

  ✅ Port 6379 = Main Redis (properly configured with password)
  ✅ Port 6380 = Test Redis (would need separate setup)
  ✅ Embedded password in URL (redis://:redis@)
  ✅ Environment variable set (REDIS_PASSWORD=redis)
  ✅ Both match = authentication succeeds


VERIFICATION
═══════════════════════════════════════════════════════════════════════════════

After the fix, you should see:

  ✓ No "NOAUTH Authentication required" errors
  ✓ Redis connection established
  ✓ Vite dev server starts normally
  ✓ Can navigate to http://localhost:5173
