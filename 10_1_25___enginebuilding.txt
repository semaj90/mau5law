trtllm-build \
  --checkpoint_dir /home/james/gemma3_trtllm_checkpoint \
  --output_dir /home/james/gemma3_engine_int8 \
  --max_batch_size 4 \
  --max_input_len 2048 \
  --max_seq_len 4096 \
  --use_gpt_attention_plugin float16 \
  --use_gemm_plugin float16 \
  --enable_context_fmha \
  --remove_input_padding \
  --int8_mode \
  --per_channel \
  --use_weight_only --weight_data_type int4

Breakdown

--int8_mode → enables INT8 quantization for activations

--per_channel → per-channel scaling (better accuracy than per-tensor)

--use_weight_only --weight_data_type int4 → INT4 weight compression

--use_gpt_attention_plugin float16 → optimized GPT attention plugin in FP16

--enable_context_fmha → FlashAttention kernel for context stage

--remove_input_padding → reduces wasted compute for padded sequences

This will try to produce an INT4+INT8 hybrid engine:

Weights: INT4 → ~50% memory reduction

Activations: INT8 → runs on Tensor Cores efficiently

Math: FP16 kernels → balance between speed and accuracy

On a 3060 Ti, this should fit your 21 GB checkpoint into ~6–7 GB VRAM at runtime with headroom for batch size 4.
