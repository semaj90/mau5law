- Processing: Linear projection (reproducible, seed=42)
- Output: 512-dim embeddings for pgvector compatibility
- Performance: <100ms conversion time
- Storage: Persistent adapter (embedding_adapter_512.pkl)

REINFORCEMENT LEARNING STRATEGY
===============================

RL Training Approach:
1. Base Model: gemma3:270m (291MB → target 350MB with LoRA)
2. Teacher Model: gemma3-legal:latest (expert knowledge)
3. Student Training: Knowledge distillation + RL fine-tuning
4. Target: 6-token timing for RL optimization
5. Framework: stable-baselines3 with PPO algorithm

Training Pipeline:
```
gemma3-legal (teacher) → Generate expert responses
    ↓
gemma3:270m (student) → Learn via RL + knowledge distillation
    ↓
Fine-tuned 350MB model → Production deployment
```

Memory Optimization for RTX 3060 Ti:
- Batch size: 1-2 (VRAM constraint)
- Gradient accumulation: 4 steps
- Mixed precision: FP16/BF16
- LoRA adapters: r=8-16 (parameter efficient)
- Expected training time: 2-4 hours

```python
import ollama

def generate_rl_training_data():
    legal_scenarios = [
        "contract termination clauses",
        "liability limitation provisions",
        "confidentiality agreements"
    ]

    training_pairs = []
    for scenario in legal_scenarios:
        # Expert response from large model
        expert_response = ollama.generate(
            model='gemma3-legal:latest',
            prompt=f"Analyze legal risks: {scenario}"
        )

        training_pairs.append({
            "state": scenario,
            "expert_action": expert_response['response'],
            "reward_signal": calculate_legal_accuracy(expert_response)
        })

    return training_pairs
```

TROUBLESHOOTING
==============

Common Issues:

1. Unicode Encoding Errors
Solution: Fixed in embedding_adapter_512.py (removed Unicode characters)

2. Ollama Model Not Found
Solution: Verify models are installed:
```bash
ollama list
ollama pull embeddinggemma:latest
```

3. CUDA Out of Memory
Solution: Reduce batch size in RL training:
```python
training_args = TrainingArguments(
    per_device_train_batch_size=1,  # Reduce from 2
    gradient_accumulation_steps=4   # Increase to maintain effective batch size
)
```

4. SvelteKit Import Errors
Solution: Use default imports for components:
```javascript
import Button from '$lib/components/ui/Button.svelte';  // ✅ Correct
// Not: import { Button } from '$lib/components/ui/Button.svelte';  // ❌ Wrong
```

5. Vector Dimension Mismatch
Solution: Always use embedding_adapter_512.py for consistent 512-dim output
