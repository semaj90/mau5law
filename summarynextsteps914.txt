### Vector Dimensions: 512
- Round number for optimal memory alignment
- Warp-aligned for GPU/SIMD operations
- Perfect for ANN engine performance
- 4x memory efficiency vs 768 dimensions

### Embedding Strategy

- Fallback: embeddinggemma

- Cache hit optimization with text hashing

### Performance Targets

- Sub-second similarity search

- Streaming ingestion to prevent memory overflow
