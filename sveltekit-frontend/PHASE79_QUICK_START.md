## What's Happening (7-Step Pipeline)

```
INPUT: File path with errors
  ↓
[STEP 1] Summarize file → Extract keywords, structure, metrics
  ↓
[STEP 2] Query database → Get errors for this file
  ↓
[STEP 3] RAG/KAG search → Find similar solutions (0-10 similarity)
  ↓
[STEP 4] Build prompt → Rich context with file + errors + KB solutions
  ↓
[STEP 5] Call LLM → Ollama gemma3-legal or Gemini (with "NO EXPLANATIONS")
  ↓
[STEP 6] Validate → 4-layer safety gate blocks documentation
  ↓
[STEP 7] Rank & output → Composite score to JSONL
  ↓
OUTPUT: data/recommendations.jsonl (ready for Phase 72)
```

## Understanding the Scores

### Validation Score (0-100%)
- **100%**: Pure code, all syntax valid
- **80-99%**: Code with minor issues
- **50-79%**: Code with warnings
- **<50%**: Rejected (documentation detected)

**Calculation**:
```
- Documentation keywords found? -40% per occurrence (capped)
- Missing code keywords? -20%
- Unbalanced braces/parens? -10% per pair
- Unbalanced quotes? -10%
```

### KB Similarity (1-10)
- **9-10**: Excellent match, apply first
- **7-8**: Good match, safe to apply
- **5-6**: Moderate match, review recommended
- **1-4**: Weak match, consider manual review

### Composite Score (0-100)
```
composite = (validation_score × 0.6) + (kb_similarity × 0.4)
```

**Examples**:
- Validation 100%, Similarity 9 → Composite 94% → **HIGH confidence**
- Validation 80%, Similarity 7 → Composite 78% → **MEDIUM confidence**
- Validation 50%, Similarity 5 → Composite 50% → **MEDIUM confidence**
- Validation 45%, Similarity 8 → Composite 56% (but **REJECTED** due to doc keywords)

## Output Format

Each line in `data/recommendations.jsonl` is valid JSON:

```json
{
  "file_path": "src/lib/utils.ts",
  "file_name": "utils.ts",
  "error_count": 8,
  "primary_error_code": "TS2322",
  "validation_score": 95,
  "cosine_similarity": 8.7,
  "similarity_rank_1_to_10": 9,
  "inverse_rank_1_to_10": 2,
  "composite_score": 88.3,
  "confidence_level": "HIGH",
  "kb_references": 3,
  "validation_issues": [],
  "generated_at": "2025-12-21T10:30:45.123Z"
}
```

**Key Fields**:
- `file_path`: Where to apply the patch
- `composite_score`: Overall quality score (0-100)
- `confidence_level`: HIGH/MEDIUM/LOW for safe application
- `kb_references`: How many KB solutions found
- `validation_issues`: What problems were detected

## Using with Phase 72

Phase 72 can now safely consume these recommendations:

```javascript
// Load JSONL
const recommendations = await fs.readFile('data/recommendations.jsonl', 'utf-8');
const patches = recommendations.split('\n')
  .filter(l => l.trim())
  .map(l => JSON.parse(l));

// Apply only HIGH confidence patches
const safe = patches.filter(p => p.confidence_level === 'HIGH');
for (const patch of safe) {
  applyPatch(patch.file_path, patch.patch_content);
}
```
