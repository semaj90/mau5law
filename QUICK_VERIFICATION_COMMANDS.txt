10. TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Problem: "column embedding does not exist"
Solution: ALTER TABLE evidence ADD COLUMN embedding vector(768);
          ALTER TABLE documents ADD COLUMN embedding vector(768);

Problem: "column title does not exist"
Solution: ALTER TABLE documents ADD COLUMN title varchar(255);

Problem: "HNSW index not found"
Solution: CREATE INDEX idx_evidence_embedding_hnsw ON evidence USING hnsw (embedding vector_cosine_ops);
          CREATE INDEX idx_documents_embedding_hnsw ON documents USING hnsw (embedding vector_cosine_ops);

Problem: "NOAUTH Authentication required" (Redis)
Solution: Check REDIS_PASSWORD=redis environment variable
          Restart SvelteKit: npm run dev

Problem: "Failed to generate embedding"
Solution: Check Ollama is running: curl http://localhost:11434/api/tags
          Pull model if missing: ollama pull embeddinggemma:latest

Problem: "Slow queries (>500ms)"
Solution: Check HNSW indexes exist and are being used
          Run: PGPASSWORD=123456 psql ... -c "EXPLAIN ANALYZE SELECT ... LIMIT 10;"
