HMR Error Auto-Solve Hook

Vite exposes an HMR error overlay, but you can also capture logs into a file for your AI agent:

Add in vite.config.ts:

import fs from "fs";

export default {
  server: {
    hmr: {
      overlay: true,
    }
  },
  plugins: [
    {
      name: "hmr-error-logger",
      handleHotUpdate(ctx) {
        if (ctx.server.ws) {
          fs.appendFileSync("hmr-errors.log", `[${new Date()}] ${ctx.file}\n`);
        }
      }
    }
  ]
}


Now every HMR error gets logged into hmr-errors.log.

🔧 4. Agentic AI Debug Loop with tmux

You can spin up a tmux session where one pane runs your app, and another runs a watcher that reads hmr-errors.log and queries your AI.

Example tmux + script idea:

#!/bin/bash
tmux new-session -d -s dev "npm run dev"
tmux split-window -h "tail -f hmr-errors.log | while read line; do ./ai-agent.sh \"$line\"; done"
tmux attach -t dev


Your ai-agent.sh can call your local LLM (Ollama, LM Studio, etc.) to propose fixes automatically.
