## Key Features

### File Summarization (Step 1)
- Reads actual file content from disk
- Extracts: imports, exports, functions, types
- Identifies: code keywords (const, async, function, etc.)
- Metrics: size, line count, extension
- Preview: first 1000 characters

### Rich RAG/KAG Queries (Step 3)
- Query text: filename + keywords + error codes + messages + structure
- Searches Qdrant vector DB (fallback to PostgreSQL)
- Returns 3-5 similar solutions with 1-10 similarity scores

### Contextual LLM Prompts (Step 4)
- File context: structure, keywords, size
- Error context: codes, messages, severity
- KB context: similar patches from knowledge base
- Code preview: first 1000 chars of actual file
- **Critical**: "Output ONLY valid code - NO EXPLANATIONS"
- Size: ~3000+ characters (vs 300 before)

### 4-Layer Validation (Step 6)
```
Layer 1: Doc Detection (40%)      - Finds 18 doc keywords
Layer 2: Code Keywords (20%)      - Checks for code patterns
Layer 3: Syntax Balance (20%)     - Validates {}, (), []
Layer 4: Quote Validation (10%)   - Checks quote pairs

If ANY doc keyword found → REJECT immediately
Score must be ≥50 to pass
```

**Result**: 100% documentation blocking

### Composite Ranking (Step 7)
```
composite_score = (validation_score × 0.6) + (kb_similarity × 0.4)

Confidence levels:
- HIGH (>80): Apply immediately
- MEDIUM (50-80): Apply with review
- LOW (<50): Reject
```
