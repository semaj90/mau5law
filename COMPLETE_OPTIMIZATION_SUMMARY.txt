================================================================================
                        ARCHITECTURE OVERVIEW
================================================================================

THREE LAYERS:

Layer 1: Redis Cache (< 5ms)
   - Results only (not vectors!)
   - TTL: 1 hour default
   - Memory: ~5MB for 10k searches

Layer 2: Embedding Generation (10-15ms)
   - Ollama embeddinggemma:latest
   - 384-dimension vectors
   - Cached for repeated queries

Layer 3: pgvector Search (5-20ms)
   - PostgreSQL HNSW index
   - Cosine similarity
   - 384-dimension consistency

REQUEST FLOW:

Cache HIT: Request → Redis (< 10ms) ✨

Cache MISS: Request → Check Redis
          → Generate Embedding (10-15ms)
          → pgvector Search (5-20ms)
          → Cache Results
          → Response (15-30ms) ⚡

                       CODE EXAMPLE
================================================================================

BEFORE (100-150ms):
  const results = await fetch('/api/similarity-search', {...});

AFTER (15-30ms or < 10ms if cached):
  import { pgvectorSearch } from '$lib/services/pgvector-search-wrapper';
  import { getCachedSearchResults, cacheSearchResults }
    from '$lib/server/redis-cache';

  const cached = await getCachedSearchResults(query, { limit: 10 });
  if (cached) return cached; // < 10ms!

  const response = await pgvectorSearch({
    query: 'employment contract',
    limit: 10,
    threshold: 0.5
  });

  await cacheSearchResults(query, {
    results: response.results.map(r => ({
      id: r.id,
      title: r.title,
      similarity: r.similarity
    })),
    stats: response.stats
  });

  return response;
