# Code Ingestion Pipeline - Integration Guide\n\n## 🎯 Overview\n\nThis guide covers the complete integration of the 8-file Code Ingestion Pipeline system:\n\n1. **Continuous Watch Mode** (TypeScript)\n2. **EmbeddingGemma Service** (Python, 768d only)\n3. **S3+S4 Hybrid Summaries** (Python)\n4. **R3 Semantic Cache** (TypeScript, Qdrant)\n5. **Pipeline Orchestrator** (TypeScript)\n6. **UI Store** (Svelte)\n7. **Docker Compose GPU** (YAML)\n8. **MinIO Storage** (Documentation)\n\n## 📁 File Structure\n\n```\ndeeds-web-app/\n├── backend/\n│   ├── watchers/\n│   │   └── code_ingest_watcher.ts          # File #1\n│   ├── services/\n│   │   ├── embedding_service.py            # File #2\n│   │   ├── summary_service.py              # File #3\n│   │   ├── requirements-embedding.txt\n│   │   └── requirements-summary.txt\n│   ├── storage/\n│   │   └── qdrant_cache.ts                 # File #4\n│   ├── pipeline/\n│   │   └── code_ingestion_pipeline.ts      # File #5\n│   ├── Dockerfile.embedding-gemma\n│   ├── Dockerfile.summary-service\n│   └── Dockerfile.pipeline\n├── sveltekit-frontend/\n│   └── src/lib/stores/\n│       └── ingestionWatcherStore.ts        # File #6\n├── docker-compose.gpu.yml                  # File #7\n├── minio/\n│   └── buckets/code_docs/\n│       └── README.md                       # File #8\n└── PIPELINE_INTEGRATION_GUIDE.md           # This file\n```\n\n## 🚀 Quick Start\n\n### Prerequisites\n\n- Docker & Docker Compose\n- NVIDIA GPU with CUDA 12.2+\n- Node.js 20+\n- Python 3.11+\n- 8GB+ VRAM (for EmbeddingGemma)\n\n### 1. Environment Setup\n\n```bash\n# Create .env file\ncat > .env << EOF\nQDRANT_API_KEY=qdrant-key-123\nMINIO_ROOT_USER=minioadmin\nMINIO_ROOT_PASSWORD=minioadmin\nEOF\n```\n\n### 2. Start Services\n\n```bash\n# Start all services with GPU support\ndocker-compose -f docker-compose.gpu.yml up -d\n\n# Verify services are running\ndocker-compose -f docker-compose.gpu.yml ps\n```\n\n### 3. Verify Health\n\n```bash\n# Check Qdrant\ncurl http://localhost:6333/health\n\n# Check EmbeddingGemma\ncurl http://localhost:8001/health\n\n# Check Summary Service\ncurl http://localhost:8002/health\n\n# Check Pipeline Orchestrator\ncurl http://localhost:3001/health\n```\n\n## 🔧 Component Integration\n\n### File #1: Code Ingest Watcher\n\n**Purpose**: Continuously monitors `.cpp`, `.hpp`, `.ts`, `.svelte`, `.md` files\n\n**Key Features**:\n- Watches multiple directories\n- Detects file changes (add/modify/remove)\n- Calculates SHA256 hashes to avoid duplicates\n- Emits events for pipeline processing\n\n**Usage**:\n```typescript\nimport { CodeIngestWatcher } from './backend/watchers/code_ingest_watcher';\n\nconst watcher = new CodeIngestWatcher();\nwatcher.on('fileChanged', (event) => {\n  console.log(`File ${event.type}: ${event.file.path}`);\n});\nawait watcher.startWatching();\n```\n\n### File #2: EmbeddingGemma Service\n\n**Purpose**: Generates 768-dimensional embeddings using Google Gemma-2B\n\n**Key Features**:\n- GPU-accelerated inference\n- Batch processing (8 items default)\n- Mean pooling + L2 normalization\n- FastAPI endpoints\n\n**Endpoints**:\n```bash\n# Generate embeddings\nPOST /embed\n{\n  \"texts\": [\"text1\", \"text2\"],\n  \"chunk_ids\": [\"chunk_1\", \"chunk_2\"]\n}\n\n# Health check\nGET /health\n\n# Statistics\nGET /stats\n```\n\n### File #3: S3+S4 Hybrid Summaries\n\n**Purpose**: Generates legal compliance (S3) + semantic (S4) summaries\n\n**Key Features**:\n- Legal pattern matching\n- Semantic concept extraction\n- Compliance scoring\n- Risk factor identification\n\n**Endpoints**:\n```bash\n# Generate summary\nPOST /summarize\n{\n  \"text\": \"document content\",\n  \"file_path\": \"path/to/file\",\n  \"language\": \"english\",\n  \"document_type\": \"legal\",\n  \"summary_type\": \"hybrid\"\n}\n\n# Health check\nGET /health\n\n# Statistics\nGET /stats\n```\n\n### File #4: R3 Semantic Cache (Qdrant)\n\n**Purpose**: Stores embeddings with cosine similarity duplicate detection\n\n**Key Features**:\n- 768-dimensional vector storage\n- Cosine similarity search\n- Automatic duplicate suppression (>95% similarity)\n- No reranking for duplicates\n\n**Usage**:\n```typescript\nimport { R3SemanticCache } from './backend/storage/qdrant_cache';\n\nconst cache = new R3SemanticCache({\n  qdrantUrl: 'http://localhost:6333',\n  collectionName: 'r3_semantic_cache',\n  vectorSize: 768,\n  similarityThreshold: 0.95\n});\n\nawait cache.initialize();\n\n// Store embedding\nconst entry = await cache.store(embedding, content, metadata);\n\n// Find duplicate\nconst duplicate = await cache.findDuplicate(embedding);\n```\n\n### File #5: Pipeline Orchestrator\n\n**Purpose**: Orchestrates the complete workflow: Watch → Chunk → Embed → Summarize → Store\n\n**Key Features**:\n- Concurrent processing (configurable)\n- Retry logic with exponential backoff\n- Metrics tracking\n- Event emission\n\n**Usage**:\n```typescript\nimport { CodeIngestionPipeline } from './backend/pipeline/code_ingestion_pipeline';\n\nconst pipeline = new CodeIngestionPipeline({\n  watcherEnabled: true,\n  embeddingServiceUrl: 'http://localhost:8001',\n  summaryServiceUrl: 'http://localhost:8002',\n  qdrantUrl: 'http://localhost:6333',\n  maxConcurrency: 4,\n  retryAttempts: 3,\n  chunkSize: 1024,\n  chunkOverlap: 256\n});\n\nawait pipeline.start();\n\npipeline.on('fileProcessed', (result) => {\n  console.log(`Processed: ${result.filePath}`);\n});\n```\n\n### File #6: Svelte Store\n\n**Purpose**: Real-time UI updates for pipeline status\n\n**Key Features**:\n- WebSocket connection management\n- Auto-reconnection with exponential backoff\n- Derived stores for metrics\n- Event history tracking\n\n**Usage**:\n```svelte\n<script>\n  import {\n    pipelineStatus,\n    isConnected,\n    processingRate,\n    successRate,\n    startPipeline,\n    stopPipeline\n  } from '$lib/stores/ingestionWatcherStore';\n</script>\n\n<div>\n  <p>Connected: {$isConnected}</p>\n  <p>Files Processed: {$pipelineStatus.metrics.filesProcessed}</p>\n  <p>Processing Rate: {$processingRate.toFixed(1)} files/min</p>\n  <p>Success Rate: {$successRate}%</p>\n  \n  <button on:click={startPipeline}>Start</button>\n  <button on:click={stopPipeline}>Stop</button>\n</div>\n```\n\n### File #7: Docker Compose GPU\n\n**Services**:\n- **Qdrant**: Vector database (port 6333)\n- **EmbeddingGemma**: Embedding service (port 8001)\n- **Summary Service**: Summary generation (port 8002)\n- **Pipeline Orchestrator**: Main orchestrator (port 3001)\n- **Redis**: Session cache (port 6379)\n- **MinIO**: Object storage (port capabilities: [gpu]\n```\n\n### File #8: MinIO Storage\n\n**Bucket Structure**:\n```\ncode_docs/\n├── chunks/          # Segmented source code\n├── embeddings/      # 768d vectors\n├── summaries/ Chunking\n```\nRead file content\n  ↓\nSplit into 1024-byte chunks (256-byte overlap)\n  ↓\nGenerate chunk IDs\n```\n\n### Step 3: Embedding Generation\n```\nBatch chunks (8 at a time)\n  ↓\nTokenize with Gemma tokenizer\n  ↓\nGPU inference (mean pooling + L2 norm)\n  ↓\nReturn 768d vectors\n```\n\n### Step 4: Duplicate Detection\n```\nQuery Qdrant with embedding\n  ↓\nCalculate cosine similarity\n  ↓\nIf similarity > 0.95: Skip (duplicate)\n  ↓\nElse: Continue to summarization\n```\n\n### Step 5: Summary Generation\n```\nAnalyze legal patterns (S3)\n  ↓\nExtract semantic concepts (S4)\n  ↓\nGenerate hybrid summary\n  ↓\nReturn with confidence scores\n```\n\n### Step 6: Storage\n```\nStore in Qdrant (embedding + metadata)\n  ↓\nStore in MinIO (chunks, embeddings, summaries)\n  ↓\nUpdate metadata files\n  ↓\nEmit completion event\n```\n\n## 📈 Performance Metrics\n\n### Expected Throughput\n- **Files/minute**: 10-20 (depends on file size)\n- **Chunks/minute**: 100-200\n- **Embeddings/minute**: 100-200\n- **Summaries/minute**: 100-200\n\n### Resource Usage\n- **GPU Memory**: 6-8 GB (EmbeddingGemma)\n- **CPU**: 2-4 cores\n- **RAM**: 4-8 GB\n- **Storage**: ~8 KB per chunk (chunk + embedding + summary)\n\n### Latency\n- **File detection**: <100ms\n- **Chunking**: <50ms per file\n- **Embedding**: 50-100ms per batch (8 chunks)\n- **Summary**: 100-200ms per chunk\n- **Storage**: <50ms per operation\n\n## 🛠️ Configuration\n\n### Pipeline Config\n\n```typescript\ninterface PipelineConfig {\n  watcherEnabled: boolean;              // Enable file watching\n
