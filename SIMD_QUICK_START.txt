================================================================================
                      PARSE MODES AVAILABLE
================================================================================

ParseMode.LEGAL_DOCUMENT
  → Extracts legal metadata (jurisdiction, court, parties)
  → Finds entities (statutes, cases, regulations)
  → Confidence scoring
  → Best for: Legal document ingestion

ParseMode.GENERIC_JSON
  → Standard JSON parsing
  → No special extraction
  → Best for: Generic data

ParseMode.TEST_RESULTS
  → Handles test output format
  → Best for: Playwright results

ParseMode.PLAYWRIGHT_DATA
  → E2E test data format
  → Best for: Test integration

ParseMode.ULTRA_PERFORMANCE
  → Maximum speed mode
  → Minimum features
  → Best for: High-throughput parsing

ParseMode.WEBGPU_ACCELERATED
  → GPU acceleration (if available)
  → Parallel processing
  → Best for: Very large documents

================================================================================
                         CODE EXAMPLES
================================================================================

Example 1: Parse Legal Document
──────────────────────────────────

import { UnifiedSIMDParser, ParseMode } from '$lib/services/unified-simd-parser';

const parser = new UnifiedSIMDParser();

const jsonString = `{
  "title": "Employment Agreement",
  "jurisdiction": "New York",
  "parties": ["Acme Corp", "John Doe"],
  "content": "...legal text..."
}`;

const result = await parser.parseOptimal(jsonString, ParseMode.LEGAL_DOCUMENT);

console.log(`Parsed in ${result.parse_time_ms}ms`);
console.log(`Found ${result.legal_entities} entities`);
console.log(`Confidence: ${result.confidence}`);


Example 2: Batch Processing
────────────────────────────

const documents = [...]; // 100 documents

for (const doc of documents) {
  const result = await parser.parseOptimal(doc.content, ParseMode.LEGAL_DOCUMENT);
  console.log(`${doc.filename}: ${result.parse_time_ms}ms`);
}
// Total: ~100-200ms vs 500-5000ms with JSON.parse


Example 3: With Error Handling
───────────────────────────────

try {
  const result = await parser.parseOptimal(jsonString, ParseMode.LEGAL_DOCUMENT);
  // Use result.data, result.legal_entities, etc.
} catch (error) {
  console.error('Parse failed:', error);
  // Fallback to JSON.parse()
  const fallback = JSON.parse(jsonString);
}


Example 4: Performance Monitoring
──────────────────────────────────

const results = [];

for (let i = 0; i < 100; i++) {
  const result = await parser.parseOptimal(jsonString, ParseMode.LEGAL_DOCUMENT);
  results.push(result.parse_time_ms);
}

const avgTime = results.reduce((a, b) => a + b) / results.length;
console.log(`Average: ${avgTime.toFixed(2)}ms`);
console.log(`Min: ${Math.min(...results)}ms`);
console.log(`Max: ${Math.max(...results)}ms`);
